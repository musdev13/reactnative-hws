<h1 align="center">React Native Homeworks</h1>

> jq is required for script work

1. change directory: example `~/reactnative-hws/`

2. run script to clone one:

```bash
bash <(curl -sSL https://raw.githubusercontent.com/musdev13/reactnative-hws/refs/heads/main/clone-hw.sh)
```

or for fish:

```fish
curl -sSL https://raw.githubusercontent.com/musdev13/reactnative-hws/refs/heads/main/clone-hw.sh -o /tmp/clone-hw.sh; and bash /tmp/clone-hw.sh
```
